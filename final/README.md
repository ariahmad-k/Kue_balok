# Sistem Informasi Penjualan UMKM Kue Balok Mang Wiro
Sistem ini dibuat untuk membantu proses penjualan, pencatatan transaksi, manajemen produk, serta laporan keuangan sederhana bagi UMKM Kue Balok Mang Wiro. Sistem dikembangkan menggunakan PHP Native dan MySQL.

## 🚀 Fitur Utama Sistem

### 👤 Super Admin (Pemilik)
- Login dan akses penuh ke seluruh sistem
- Statistik penjualan (grafik harian/bulanan)
- Laporan penjualan lengkap
- Manajemen pengguna (admin & kasir)
- Manajemen produk dan stok
- Akses data penjualan & riwayat transaksi

### ⚙️ Admin
- Login ke dashboard admin
- Manajemen produk/menu
- Manajemen stok barang
- Akses data penjualan sederhana

### 🛒 Kasir
- Login ke dashboard kasir
- Input transaksi penjualan
- Melihat riwayat transaksi
- Cetak struk sederhana
